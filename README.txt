This folder currently has one placeholder image: patnitop-hero.jpg
It is only used for social-media link previews (Open Graph). It is a plain
text graphic, not a real photo, so no false or misleading images are shown.

The rest of the website intentionally has NO images yet — no stock photos,
no downloaded internet photos. That is deliberate: using photos you don't
own can cause copyright problems, and fake/generic tourism photos look
unprofessional once a real customer notices.

TO ADD YOUR OWN REAL PHOTOS LATER (see the "How to add real photos" step
in the setup guide you were given):
1. Take or collect real photos: your cars, Patnitop views, your team, a
   hotel room you've booked for a guest, etc. Phone photos are fine if
   they're clear and in landscape orientation.
2. Resize each photo so its longest side is about 1600px (keeps the
   website fast). Any free online image resizer works.
3. Save it into this /images folder with a simple lowercase file name,
   e.g. patnitop-hero.jpg, dzire-car.jpg, nathatop-view.jpg.
4. In the relevant .html file, add an <img> tag, for example:
   <img src="images/patnitop-hero.jpg" alt="View of Patnitop meadows">
   Always fill in the alt="" text — it helps Google understand the image
   and helps SEO.
5. Replace patnitop-hero.jpg with a real photo once you have one — this
   is the image people will see when your link is shared on WhatsApp,
   Facebook, or Google search results.
