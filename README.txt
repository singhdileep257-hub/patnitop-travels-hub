Patnitop Travels Hub — static website
======================================
Pages are GENERATED by build.py. Do not edit the .html files by hand.

  python3 build.py            regenerate every page, sitemap.xml, robots.txt, js/agent-data.js
  python3 tests/check_site.py static checks (SEO, links, sitemap, no invented claims)

Settings:   site.config.json   (site address, Google Analytics ID, lead sheet link)
Fares:      data/rates.json    (ships empty: the assistant quotes no price until you add verified ones)
Lead sheet: apps-script/lead-receiver.gs
Full guide: docs/SETUP.md      (deploy, domain, Search Console, lead sheet, analytics)
Photos:     images/photography/<slug>.jpg shows on the couple-shoot page cards (slugs in build.py).
            Add only photos you own or have written permission to use, then run build.py.
Portfolio:  data/photographer-portfolio.json + images/photography/portfolio/ (couple-shoot page).
            A photo shows ONLY with "approved": true plus who approved it and when; with none, a plain
            "coming soon" note shows instead. The photographer's Instagram link is
            photographer_instagram_url in site.config.json (hidden while empty).
            python3 tests/portfolio.test.py checks all of this against throw-away copies of the site.
